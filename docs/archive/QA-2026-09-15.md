## Additional source-backed fixes

- Literal comment/reply/quote text no longer double-encodes `<`, `>`, and `&`.
- Reply drafts and focus survive realtime list updates. Thread-level pending state prevents a rebuilt reply form from submitting duplicates; successful completion clears only the submitted draft.
- Comment composer/reply footers use consistent alignment and mobile stacking.
- Per-thread-query author lookups are shared for repeated authors.
- Failed tree expansion no longer creates an unbounded 50ms polling loop; failed pagination exposes Retry.
- Document navigation and shell-toggle messages require the current content iframe; invalid path segments are rejected.
- Publication create/remove use confirmed mutation results without four redundant metadata GETs.
- Settings/Teams fetch only organization data; People additionally fetches invitations; Overview loads all three collections. Unused invitation/project requests no longer block unrelated pages.
- Batch invitation retries retain the exact failed rows; successful rows are removed by the caller.
- Clipboard failures produce feedback rather than premature “Copied” states.
- Empty-state icons preserve actual Material Symbols instead of being replaced by placeholder letters or the generic inbox icon.
- Auth return destinations reject backslashes and control characters.
- Invitation return destinations are preserved through verification and account recovery.
- Reduced-motion overrides, focus styles, and sandboxed 404 navigation fallback were improved.
- Private-share listing previously limited the organization-wide query to 200 before filtering by project, so newer sibling-project shares could hide the target project's shares. The deployed query now uses an organization/project/created-time index before the per-project limit. A Convex regression covers 201 newer sibling-project grants and a mismatched organization.
- Extended private-share route tests cover malformed/traversal paths, outside-directory assets, denied-path zero storage reads, and response sandbox/no-store/referrer headers.
