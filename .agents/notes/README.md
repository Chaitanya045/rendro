# Agent notes

Working notes for agents (and humans) picking up Rendro work. These are
observations and decisions with context, not a replacement for `docs/`.
`docs/TECHNICAL.md` stays the source of truth for how the system works.

| File | What it holds |
|---|---|
| [architecture.md](architecture.md) | How the codebase is put together today, and where the sharp edges are |
| [orchestration.md](orchestration.md) | How production-readiness work is run: issues, branches, fixers, review, merge, deploy |
| [roadmap.md](roadmap.md) | The modernization, security, performance and coverage plan, with links to issues |
| [ui-inventory.md](ui-inventory.md) | Every route and UI transition family, the starting point for the regression registry |

Keep entries dated. When something here goes stale, fix or delete it rather
than appending a contradiction. The repository is public: never record
secrets, credentials, account details or exploit specifics here.
